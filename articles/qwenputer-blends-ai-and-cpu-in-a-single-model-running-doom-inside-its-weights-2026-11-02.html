Qwenputer Blends AI and CPU in a Single Model, Running Doom Inside Its Weights

2026-11-02 · 3 min read
An experimental Qwen 3.5 4B LLM now contains a 32‑bit RISC‑V CPU, enabling it to execute code and even run the classic game Doom directly from its neural weights.

In a surprising twist on the line between artificial intelligence and traditional computing, a team of researchers has embedded a 32‑bit RISC‑V CPU directly into the weights of the Qwen 3.5 4B large language model (LLM). The resulting system, dubbed Qwenputer, can compile and execute C code, perform arithmetic operations, and even run the classic first‑person shooter Doom – all from within the neural network itself.

How Qwenputer Works

The core idea is to treat the neural weights as a form of memory that can store executable instructions. By compiling a lightweight RISC‑V processor into the model’s parameters, the system can interpret and run code without relying on an external CPU. When a user asks the model to perform a calculation or run a program, the Qwenputer interprets the request, generates the corresponding machine code, and executes it inside the same neural fabric that answers the question.

Running Doom Inside an LLM

To demonstrate the capability, the developers compiled the original Doom engine – a 1993 first‑person shooter – into the Qwenputer’s weights. When prompted, the model launches the game, rendering graphics and handling user input entirely within its own architecture. The result is a self‑contained system that can play a full game without any external dependencies.

Implications for Software Development

While still experimental, Qwenputer illustrates a new paradigm for software deployment. Traditional applications require separate binaries, operating systems, and runtime environments. In contrast, an AI model that includes its own processor can carry both the logic and the execution engine in a single package. This could simplify distribution, reduce attack surfaces, and enable more flexible deployment on edge devices.

Current Limitations and Future Work

At present, the embedded CPU is limited to 32‑bit RISC‑V, which constrains performance and memory usage. The model’s size – 4 billion parameters – also imposes practical limits on the complexity of programs it can run. Researchers are exploring ways to scale the approach, integrate more powerful processors, and optimize the compilation pipeline to support larger applications.

Conclusion

Qwenputer represents a bold step toward blurring the lines between AI and conventional software. By embedding a CPU directly into a language model’s weights, the team has shown that neural networks can not only generate code but also execute it. As the field matures, we may see more hybrid systems that combine the flexibility of AI with the reliability of traditional computing.
