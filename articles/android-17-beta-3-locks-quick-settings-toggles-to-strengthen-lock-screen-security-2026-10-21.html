Android 17 Beta 3 Locks Quick‑Settings Toggles to Strengthen Lock‑Screen Security

2026-10-21 · 3 min read
Google’s latest Android 17 beta patch now lets users lock Wi‑Fi, Bluetooth, Mobile Data and Airplane Mode toggles on the lock screen, addressing a major security flaw.

Google’s Android 17 beta 3 release brings a critical security improvement that finally allows users to lock the Quick‑Settings toggles on the lock screen. The update addresses a long‑standing vulnerability that let anyone toggle Wi‑Fi, Bluetooth, Mobile Data or Airplane Mode without unlocking the device.

What the patch does

The new beta fixes a flaw in the Quick‑Settings UI that exposed the toggle controls to anyone who could access the lock screen. With the patch, users can now set a lock‑screen preference that requires a PIN, pattern or biometric authentication before any of the four toggles can be changed.

Why it matters

Unrestricted access to these toggles could let malicious actors disable network connections or enable data usage without the owner’s knowledge. By forcing authentication, the update reduces the risk of unauthorized network manipulation and protects user privacy.

How to get the update

Android 17 beta 3 is available through the Android Beta Program. Users who have enrolled in the beta channel can download the update via Settings > System > Advanced > System update. The patch is expected to roll out to production devices in the coming weeks.
