Google Unveils TPU 8i Max and TPU 8tx for Long‑Context AI Agents and Secure Inference

2026-11-12 · 3 min read
Google expands its TPU lineup with two new chips that combine long‑context processing and confidential inference, targeting AI agents and security workloads.

Google has added two new specialized chips to its eighth‑generation Tensor Processing Unit (TPU) family, the TPU 8i Max and TPU 8tx. Both chips reuse the silicon from the earlier TPU 8i and TPU 8t, but they are packaged together on a single die to deliver higher performance for specific workloads.

Long‑Context AI Agents

The TPU 8i Max is designed for AI agents that require extended context windows. By integrating two TPU 8i cores into one package, the chip can handle longer sequences of data, which is essential for conversational models and other applications that need to remember more context over time.

Confidential Inference

The TPU 8tx targets secure inference workloads. It swaps the traditional ARM host with an AMD EPYC processor, providing a more powerful host environment for confidential AI tasks. This configuration is aimed at enterprises that need to run sensitive models while maintaining data privacy.

Implications for the Cloud Market

With these additions, Google is reinforcing its position in the cloud AI hardware market. The new chips allow customers to run more complex agents and secure inference workloads on Google Cloud’s infrastructure, potentially reducing the need for external hardware solutions.
