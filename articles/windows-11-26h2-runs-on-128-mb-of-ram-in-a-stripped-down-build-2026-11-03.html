Windows 11 26H2 Runs on 128 MB of RAM in a Stripped‑Down Build

2026-11-03 · 3 min read
A developer has shown Windows 11 26H2 can operate with just 128 MB of memory, retaining basic desktop functions in a minimal installation.

In a striking demonstration of Windows 11’s lean potential, a developer has managed to run the 26H2 update on a machine with only 128 MB of RAM – a mere 3.1 % of the operating system’s recommended minimum. The experiment strips the OS down to its essentials, leaving only the Desktop, File Explorer and Notepad available for use.

How the Minimal Build Works

The developer disabled non‑essential services and removed background processes that normally consume memory. By doing so, the system can boot and provide a functional user interface, albeit at a noticeably slower pace. The result is a proof‑of‑concept that Windows 11 can survive on hardware far below the typical specifications.

Implications for Low‑End Devices

While the installation is too sluggish for everyday tasks, the experiment highlights the potential for Windows 11 to run on low‑end or legacy hardware. It could inform future lightweight editions or help developers understand the OS’s core memory footprint.

Limitations and Future Work

The stripped‑down build lacks many features, such as the Start menu, taskbar, and modern UI elements. Performance remains a concern, and the setup is not intended for production use. Further research could explore optimizing the OS for embedded or IoT devices.
