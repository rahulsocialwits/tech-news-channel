Samsung Galaxy S24 Series Gets First Major Update, But One UI 9 Still Missing

2026-09-30 · 3 min read
Samsung’s Galaxy S24 phones receive a new software update that improves security and performance, yet the long‑awaited One UI 9 hasn’t arrived.

Samsung’s flagship Galaxy S24 series has just received its first major software update, bringing a host of security patches and performance tweaks to the devices. The update, rolled out on September 30, 2026, focuses on keeping the phones safe and stable, but it does not include the highly anticipated One UI 9 interface.

What the Update Covers

The new firmware includes critical security fixes that address vulnerabilities discovered in the previous Android 16 build. It also optimizes background processes, reducing battery drain and improving overall responsiveness. Users report smoother multitasking and faster app launch times after installing the update.

One UI 9 Still on the Horizon

While the update enhances security, Samsung has not yet released One UI 9, the next major iteration of its custom Android skin. The company’s roadmap indicates that the new UI will arrive in the next few months, but no specific release date has been announced. Until then, Galaxy S24 owners will continue to use the current One UI 10 interface.

How to Update Your Galaxy S24

To install the latest firmware, open the Settings app, tap Software update, and select Download and install. The process typically takes 15–20 minutes, depending on the device’s storage capacity and internet speed.

What This Means for Users

For now, Galaxy S24 users can enjoy a more secure and efficient experience, but they will still wait for the visual and functional improvements promised by One UI 9. Samsung’s focus on security patches demonstrates the company’s commitment to protecting user data while it finalizes the next UI overhaul.
